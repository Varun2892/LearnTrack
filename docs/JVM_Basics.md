# JVM Basics

## JDK
JDK is used to develop Java applications. It contains the compiler and JRE.

## JRE
JRE provides libraries and JVM required to run Java programs.

## JVM
JVM executes Java bytecode and enables platform independence.

## Bytecode
Java source code is compiled into bytecode which runs on the JVM.

## Write Once, Run Anywhere
Java programs can run on any operating system that has a JVM.
